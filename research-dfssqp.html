Current research project

Equality-Constrained Single-Index Learning via DF-SSQP

A methodological study of derivative-free stochastic SQP for a constrained profile-optimization problem whose objective can only be evaluated through stochastic inner training and noisy scalar validation feedback.

Work in progress with Prof. Sen Na Georgia Tech ISyE stochastic black-box optimization
Overview

Optimization methodology first

The outer decision variable is a response-directed direction w. For every candidate direction, a neural prediction model is retrained using a fixed finite-step stochastic procedure. The resulting validation loss is one noisy scalar oracle evaluation for DF-SSQP, while the unit-norm equality constraint identifies a direction rather than an arbitrary scale.

ROLE

Future benchmark-risk forecasting is the real-data testbed. The primary research focus is optimization in the stochastic, equality-constrained, zero-order setting.

Questions

Two levels of inquiry

Primary · Methodological

Can DF-SSQP optimize an equality-constrained direction when every objective evaluation requires stochastic inner training?

The optimizer observes neither derivatives nor fitted inner parameters—only noisy scalar validation losses.

Secondary · Application

Does a response-directed scalar index of industry risk add predictive information for future benchmark risk?

The index is evaluated after controlling for the benchmark’s current aggregate risk state.

Formulation

A stochastic profile objective

The inner model maps the industry-risk vector to a scalar index, while the outer problem selects the index direction from noisy validation feedback.

Inner prediction model
ŷt = βut + Fθ(w⊤zt)

The neural link receives only the scalar index. The coefficient β separately controls for current aggregate benchmark risk.

Outer optimization problem
min Eξ[L(w, ξ)]   s.t.   ‖w‖2 = 1

The expectation is over stochastic inner-training randomness; DF-SSQP accesses noisy realizations of the scalar validation loss.

What one outer evaluation requires

The expensive, noisy mapping from a candidate direction to validation loss is treated as a black-box oracle.

Reframing

Response-directed single-index learning

Replaced date-specific portfolio decisions with one common direction that summarizes cross-sectional industry-risk information.

Profile objective

Inner training and scalar validation feedback

Current formulation

Unit-norm equality-constrained black-box optimization

Uses the sphere constraint to identify the index direction while preserving the nonlinear equality structure targeted by DF-SSQP.
